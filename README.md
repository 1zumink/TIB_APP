# TIB — приложение для команды

Кроссплатформенное приложение (iOS + Android + web) для небольшой команды дизайнеров.
Стилистика: **helvetica swag** — жирная типографика, чёрный / белый / красный `#FF0044`.

## Что внутри

| Раздел | Что делает |
| --- | --- |
| 🏠 **Главная** | Приветствие, ближайший co-work, ближайший дедлайн, быстрые ссылки |
| 🔥 **Дедлайны** | Общая таблица дедлайнов. Каждый может добавить/изменить, назначить ответственного, отметить готовым. Цветовая индикация срочности |
| ✅ **Таски** | Задачи, которые может закрыть кто-то один. «Беру на себя» → видно, кто делает. Название, описание, дедлайн |
| ✨ **Ивенты** | Митапы, хакатоны, конфы. Добавить ивент или отметить «я иду» на чужой |
| 👤 **Профиль** | 3D-карточка **TIB_ID** — крутится пальцем. Переключение «кто ты» (демо), статистика |
| 📅 **Общие часы** | Расписание совместной работы по дням недели. Отметься — команда видит, кто в деле (из профиля) |
| 📄 **Лог работ** | Кто что сделал + когда (автор и время проставляются автоматически). **Экспорт в Excel одним тапом** (из профиля) |

## Технологии

- **Expo (React Native)** — один код на iOS / Android / web
- **expo-router** — навигация, нижний таб-бар
- **react-native-reanimated + gesture-handler** — 3D-карточка TIB_ID
- **xlsx + expo-sharing** — экспорт лога в `.xlsx`
- **AsyncStorage** — локальное сохранение данных

## Запуск

```bash
npm install
npx expo start
```

Дальше:
- **iOS**: нажми `i` (нужен Xcode) или отсканируй QR в приложении **Expo Go** на айфоне
- **Android**: нажми `a` (нужен Android Studio) или Expo Go
- **Web**: нажми `w` (быстрый предпросмотр в браузере)

Проще всего для теста на телефоне — поставить **Expo Go** из App Store / Google Play и отсканировать QR-код из терминала.

## Дизайн-плейсхолдеры

- **Карточка TIB_ID** (`src/components/TibCard3D.tsx`) — заглушка. Логика вращения готова, дизайн лицевой/оборотной стороны легко заменить на финальный.
- **Логотип** взят из `references/tiblogo.svg` → `src/components/TibLogo.tsx`.

## Дальнейшие шаги (синхронизация между друзьями)

Сейчас данные хранятся локально на устройстве (демо-режим с переключением пользователя).
Чтобы дедлайны/таски/лог реально синхронизировались между всеми, нужно подключить общий бэкенд.
Слой данных изолирован в `src/store/StoreContext.tsx` — все действия (`addDeadline`, `claimTask`, `addLog`, …)
в одном месте, поэтому переход на **Supabase** (или Firebase) сведётся к замене реализации этих методов,
без переписывания экранов.

## Структура

```
app/                     экраны (expo-router)
  (tabs)/                таб-бар: index, deadlines, tasks, events, profile
  schedule.tsx           общие часы
  worklog.tsx            лог работ + экспорт
src/
  theme.ts               дизайн-система (цвета, типографика)
  types.ts               модели данных
  store/                 состояние + сид-данные + персист
  components/            UI-примитивы, 3D-карточка, формы, лого
  lib/                   даты, экспорт в Excel
references/              референсы и логотип
```
